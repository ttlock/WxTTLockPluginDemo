# 通通锁接口返回结果对象说明  
[返回接口文档](../../README.md)
<br />

## <span name="TTLockWifiFromScan">TTLockWifiFromScan 扫描返回的wifi信息</span>  
 |NAME          |TYPE       |VERSION    |DESCRIPTION|
 |--------------|-----------|-----------|-----------|
 |SSID          |string     |           |wifi名称|
 |rssi          |number     |           |信号值|
<br />

## <span name="TTLockWifiInfo">wifi配置信息 TTLockWifiInfo</span>  
 |PARAMS                |TYPE               |REQUIRED      |IN/OUT          |DESCRIPTION|
 |----------------------|-------------------|--------------|----------------|-----------|
 |SSID                  |string             |Y             |IN              |wifi名称|
 |password              |string             |Y             |IN              |wifi密码|
<br />

## <span name="TTLockServerIPAddress">远程服务器配置信息 TTLockServerIPAddress</span>  
 |PARAMS                |TYPE               |REQUIRED      |IN/OUT          |DESCRIPTION|
 |----------------------|-------------------|--------------|----------------|-----------|
 |server                |string             |N             |IN              |服务器域名地址，server与ipAddress二选一，**优先生效**|
 |ipAddress             |string             |N             |IN              |服务器IP地址，server与ipAddress二选一|
 |port                  |number             |Y             |IN              |服务器端口地址|
<br />

## <span name="TTLockStaticIPAddress">固定IP配置信息 TTLockStaticIPAddress/span>  
 |PARAMS                |TYPE           |REQUIRED      |IN/OUT          |DESCRIPTION|
 |----------------------|---------------|--------------|----------------|-----------|
 |ipAddress             |string         |Y             |IN              |固定IP地址|
 |subnetMask            |string         |Y             |IN              |子网掩码|
 |router                |string         |Y             |IN              |默认网关|
 |dns1                  |string         |Y             |IN              |首选DNS|
 |dns2                  |string         |Y             |IN              |备用DNS|
<br />

## <span name="TTLockLocaleIPAddress">本地IP地址配置信息 TTLockLocaleIPAddress/span>  
 |PARAMS                |TYPE                                                   |REQUIRED      |IN/OUT          |DESCRIPTION|
 |----------------------|-------------------------------------------------------|--------------|----------------|-----------|
 |useDHCP               |boolean                                                |Y             |IN              |是否使用DHCP动态获取|
 |ipAddress             |[TTLockStaticIPAddress](#TTLockStaticIPAddress)        |N             |IN              |固定IP地址，useDHCP=false时必填|
<br />
